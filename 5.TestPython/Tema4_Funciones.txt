1. En Python, para definir una función se utiliza la palabra clave ____.

a) def
b) func
c) function
d) define

Respuesta: a) 

2. El siguiente código: def saludar(): print("Hola mundo") define una función que ____.

a) retorna None explícitamente
b) genera un error de sintaxis
c) no retorna ningún valor explícito
d) retorna "Hola mundo"

Respuesta: c) 

3. Para llamar a una función en Python, se utiliza ____.

a) el nombre de la función seguido de paréntesis
b) la palabra clave invoke seguida del nombre de la función
c) la palabra clave call seguida del nombre de la función
d) el nombre de la función precedido por @

Respuesta: a) 

4. En la siguiente función: def suma(a, b=5): return a + b, el parámetro b es ____.

a) un parámetro obligatorio
b) un parámetro con valor predeterminado
c) un parámetro de solo lectura
d) un parámetro de tipo entero

c) 12
d) 3 * 4
